# AdminWordmark

The name mark of the admin: a building icon and company name, shown on the login screen, the home screen, and the expanded desktop sidebar. In the collapsed sidebar, the brand link becomes a Home icon.

Source: `samjhana-admin/src/components/brand/Wordmark.jsx`; the text is the translation `home.title`.

## Rules
- Sizes: `lg` (text-2xl, 28 px icon) and `md` (text-xl, 24 px icon). Bold.
- It takes its colour from the parent: white on the dark core bar, core-800 on white.
- The name always comes from the translation, never typed into a screen. Both languages are required.
- The admin has no image logo. The public website has its own mark (see [Logos](../../assets/Logos/README.md)).
