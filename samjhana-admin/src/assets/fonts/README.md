# Bundled Nepali font

`Kalimati.ttf` is Kalimati Regular version 1.20. It is bundled so the Nepali admin UI renders consistently instead of depending on fonts installed on each device.

- Source package: [Nepal Government Loan Recovery Tribunal](https://giwmscdnone.gov.np/media/files/kalimati-regular_72a1oit.zip)
- Original filename: `Kalimati Regular.otf`
- SHA-256: `4710a0ccab977f8911525f5a98ee60ed65239b6241e65e424158f337be4dc8b5`
- Verified: 2026-10-17

The government download contains the font and a generic readme, but no formal license text. Confirm redistribution terms before reusing this font outside this application.
